# Foundation-model embeddings

Prepare the common allele catalogue first, then run AgroNT, PlantCAD2, and GPN
in their separate environments. Copy each `config.example.json` to
`config.json`, edit only paths, and run the model's smoke test before production
inference. All three analyses use reference-anchored regressions and the same
deterministic allele-label permutation design.

Dedicated model-summary and enrichment plots are generated by
`figures/03_embeddings/`.
